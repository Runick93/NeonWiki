# 📁 Wiki de Ejemplo

Esta carpeta contiene archivos de ejemplo para probar **NEON WIKI v3.1**.

## Archivos incluidos

- `01_Bienvenida.md` - Introducción y características
- `02_Tecnico.md` - Guía técnica del renderizado seguro

## Cómo usar

1. Abrir NeonWiki.exe
2. Click en "📁 Select Wiki Folder"
3. Seleccionar esta carpeta (`WikiExample`)
4. Explorar los archivos en el TreeView
5. Click en cualquier archivo para abrirlo
6. Cambiar entre tabs VIEW y EDIT

## Agrega tus propios archivos

Simplemente crea archivos `.md` en esta carpeta y aparecerán automáticamente en el TreeView.
