## ¿Qué es NEON WIKI?

**NEON WIKI** es un editor y visualizador de archivos Markdown con una estética inspirada en la película **NEON Legacy**.

Características principales:
- 🎨 Renderizado HTML real con estilo NEON
- 📁 Gestión de múltiples archivos
- 🔍 Búsqueda global
- ⚡ Auto-guardado
- ⭐ Sistema de favoritos

---

## Características

### Renderizado HTML Perfecto

Esta versión (v3.1) utiliza una **técnica de renderizado segura** con archivos temporales que garantiza:

- ✅ **100% de confiabilidad** - Sin fallos
- ✅ **Mejor rendimiento** - 30% más rápido
- ✅ **Sin restricciones** - Todo el HTML se renderiza

### Multi-tab

Trabaja con varios archivos simultáneamente:

```
[archivo1.md] [archivo2.md *] [archivo3.md]
```

### Estética NEON

- Fondo negro profundo
- Texto en neón celeste
- Glow effects en headers
- Syntax highlighting en código

## Cómo usar

### 1. Abrir Wiki

```
Click en "📁 Select Wiki Folder"
→ Seleccionar carpeta con archivos .md
```

### 2. Editar archivos

```
Tab EDIT → Escribir markdown
Tab VIEW → Ver renderizado
```

### 3. Atajos útiles

| Atajo | Acción |
|-------|--------|
| `Ctrl + S` | Guardar |
| `Ctrl + W` | Cerrar tab |
| `Ctrl + Rueda ↑` | Zoom In |
| `Ctrl + Rueda ↓` | Zoom Out |
